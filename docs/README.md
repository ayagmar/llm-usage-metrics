## Documentation Structure

- `docs/` - Internal contributor docs (this folder)
- `site/src/content/docs/` - User-facing documentation (canonical source), including the library pages under `library/`
- `site/src/content/docs/cli-reference.mdx` and `security.mdx` - Generated by `pnpm run site:docs:generate`; do not edit by hand

The project follows a "docs in code" approach where user-facing documentation is authored alongside the website and deployed automatically.
