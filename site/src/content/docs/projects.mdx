## Where a project comes from

A project is the working directory that the coding tool recorded for the session. Events store it as `repoRoot`, but the CLI does not look for a `.git` folder, so a session started in a subfolder counts as its own project. Claude Code, Codex, Droid, dsh, Gemini, OpenClaw, OpenCode, and pi record a working directory. Usage from the other sources, and sessions where the tool recorded none, is listed as `(unattributed)`.

The label is the last folder name of the path. When two projects end in the same folder name, both labels gain parent folders until they differ: `/work/a/api` and `/work/b/api` become `a/api` and `b/api`. A label stays the same across every period of one report. `session`, `value`, `trends --by-repo`, `compare --by-repo`, the `--by-repo` splits of the usage reports, and the interactive report label projects the same way.

## Set the window

Without date flags, `projects` covers your full history. `--last N` covers the last N months, counting the current one; `--since` and `--until` take inclusive dates in the reporting timezone.

```bash
llm-usage projects --last 3 --top 0
llm-usage projects --since 2026-06-01 --until 2026-06-30
```

The report lists the 10 costliest projects; `--top N` lists N, and `--top 0` lists every project. The limit applies to `--json` as well. The `TOTAL` row and the JSON `totals` still count every project in the window, and a note on `stderr` says how many were left out.

## Projects per period

```bash
llm-usage projects --granularity monthly
```

`--granularity daily`, `weekly`, or `monthly` adds a second table with one row per period and project (cost, tokens, and models), for the projects the first table lists. Rows are ordered by period, then by label, with `(unattributed)` last.

## Narrow the scope

The shared filters apply: `--source`, `--provider`, `--model`, `--machine`, `--timezone`, pricing flags, and `--no-history`. `--repo` keeps some projects only:

```bash
llm-usage projects --repo api
llm-usage projects --repo ~/work --granularity weekly
```

A path (absolute, or starting with `./`, `../`, or `~/`) matches that directory and every project under it. A name or path tail such as `api` or `work/api` matches projects whose path ends with it. `(unattributed)` matches usage without a project. The same flag works on most reports; see each command's `--help`.

## Output

`projects` supports terminal, `--json`, and `--markdown` output, but not `--share`; the [interactive report](/llm-usage-metrics/share/) of any usage command has its own projects table with a drill-down into sessions. `--compact` abbreviates token counts and drops the Events and Active Days columns; `--no-cost` drops Cost and Share. Neither works with `--json`.

```bash
llm-usage projects --granularity monthly --json
```
