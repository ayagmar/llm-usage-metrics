## Default location

- `$GEMINI_CLI_HOME/antigravity-cli/conversations/*.db` when `GEMINI_CLI_HOME` is set
- `~/.gemini/antigravity-cli/conversations/*.db`

## Override

```bash
llm-usage daily --source antigravity --antigravity-dir /path/to/antigravity/conversations
```

`antigravity` is directory-backed, so generic source directory overrides also work:

```bash
llm-usage daily --source-dir antigravity=/path/to/antigravity/conversations
```

## Parsing notes

The adapter reads Antigravity CLI SQLite conversation databases in read-only mode. Token usage is stored in protobuf blobs: input and cache-read tokens map directly, output includes thinking tokens (they are billed at the output rate) with reasoning kept as a breakdown, and repeated response ids are counted once. The usage message's first field repeats the request's model enum and is not counted as tokens. Claude model names carry Antigravity's effort suffix (`claude-opus-5-5-medium`) and are priced as the base model.
