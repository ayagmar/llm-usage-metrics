## Default locations

- `~/.claude/projects/**/*.jsonl`
- `~/.claude/transcripts/**/*.jsonl`

When `CLAUDE_CONFIG_DIR` is set, the `projects` and `transcripts` directories under it replace `~/.claude`. A comma-separated value scans several config directories.

## Override

```bash
llm-usage daily --claude-dir /path/to/.claude/projects
# or
llm-usage daily --source-dir claude=/path/to/.claude/projects
# several directories (repeat the flag)
llm-usage daily --claude-dir /work/.claude/projects --claude-dir /home/me/.claude/projects
```

## Parsing notes

The adapter reads Claude Code assistant transcript rows with `message.usage`, including nested subagent transcripts.
`cache_creation.ephemeral_1h_input_tokens`, when present, marks the part of `cache_creation_input_tokens` written to the one-hour cache, which is priced at the one-hour rate (see [Pricing](/llm-usage-metrics/pricing/#cache-writes)). `output_tokens` already includes extended thinking; `output_tokens_details.thinking_tokens`, when present, fills the reasoning breakdown without changing output, total, or cost.
Streaming/update rows are de-duplicated by message id plus request id, so only the final observed usage row per request is counted while retries count separately.
Forked subagents (`isFork` in the `agent-<id>.meta.json` sidecar) begin with a replay of their parent's conversation; rows whose message id and request id also appear in the parent transcript (`parentAgentId`, or the main session transcript) are skipped because the parent already counts them. This applies only when the parent lies under a scanned Claude directory; otherwise the replayed rows are kept.

Claude model rows default to provider `anthropic`; rows that declare another provider keep that provider.
