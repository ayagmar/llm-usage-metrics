## Default location

- `~/.codex/sessions/**/*.jsonl` (or `$CODEX_HOME/sessions/**/*.jsonl` when `CODEX_HOME` is set)

## Override

```bash
llm-usage daily --codex-dir /path/to/codex/sessions
# or
llm-usage daily --source-dir codex=/path/to/codex/sessions
# several directories (repeat the flag)
llm-usage daily --codex-dir /path/one/sessions --codex-dir /path/two/sessions
```

## Parsing notes

The adapter handles Codex token-count events and computes deterministic usage deltas for cumulative counters. Newer Codex releases also write one `token_usage_record` row per API response; when a session has them, the adapter emits those records (deduplicated by `response_id`) instead of the deltas, which recovers the response that triggers an auto-compaction (the cumulative counters never include it) and maps `cache_write_input_tokens`.
