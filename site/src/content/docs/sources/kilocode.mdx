## Default location

- VS Code global storage for extension `kilocode.kilo-code`: `User/globalStorage/kilocode.kilo-code/tasks/*/ui_messages.json`
- Remote VS Code server storage: `~/.vscode-server/data/User/globalStorage/kilocode.kilo-code/tasks/*/ui_messages.json`

## Override

```bash
llm-usage daily --source kilocode --kilocode-dir /path/to/kilocode/tasks
```

`kilocode` is directory-backed, so generic source directory overrides also work:

```bash
llm-usage daily --source-dir kilocode=/path/to/kilocode/tasks
```

## Parsing notes

KiloCode shares the Cline task format. The adapter reads `ui_messages.json` usage payloads, keeps positive USD `cost` values as explicit cost, and reads the model from sibling `api_conversation_history.json`.
