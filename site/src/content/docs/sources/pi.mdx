## Default locations

- `~/.pi/agent/sessions/**/*.jsonl`
- `~/.omp/agent/sessions/**/*.jsonl` (Oh-My-Pi fork)

## Override

```bash
llm-usage daily --pi-dir /path/to/pi/sessions
# or
llm-usage daily --source-dir pi=/path/to/pi/sessions
```

## Parsing notes

The adapter reads `session`, `model_change`, and `message` records and extracts token/cost usage from message usage payloads.

Forked sessions start with a copy of the parent's entries, keeping their original ids and timestamps. When a `session` header carries `parentSession` and that parent file still exists, entries timestamped before the fork are skipped because the parent already counts them. If the parent file is gone, the fork's copies are counted, since they are the only remaining record of that usage.
